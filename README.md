# 🎧 Featured Project — Sonique IVI Audio Player

<div align="center">

<img src="https://img.shields.io/badge/SONIQUE-IVI%20AUDIO%20PLAYER-00C2FF?style=for-the-badge&labelColor=0D1117"/>

<br/>

**Sonique** is the graduation project in this repository: an **In-Vehicle Infotainment (IVI) audio-player application** designed around **USB and Bluetooth audio sources**.

The project represents the integration stage of the training, bringing together software-development fundamentals with Linux and Qt-based application development in an automotive-oriented use case.

### Project Focus

- 🎵 IVI audio-player experience
- 🔌 USB audio/media workflow
- 📶 Bluetooth-oriented audio integration
- 🖥️ Qt-based graphical user interface
- ⚙️ C++ application logic
- 🐧 Linux development environment
- 🧩 Integration of multiple software layers into one final project

### Why this project matters

Sonique moves beyond isolated exercises and demonstrates the transition from learning individual technologies to **building an integrated software product**.

> **The goal is not only to write code — but to connect components, design user interaction, solve integration challenges, and deliver a complete engineering solution.**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mohamedabdelmajeed-eng/ITI.git
cd ITI
```

Explore any training area:

```bash
cd "C++"
```

or:

```bash
cd Linux
cd QT
```

To explore the graduation project:

```bash
cd Grad_Project/Sonique_IVIAudioPlayer_USB_Bluetooth_Final
```

> Build and runtime requirements may differ between exercises and the graduation project. Check the files inside each module for its specific configuration.
