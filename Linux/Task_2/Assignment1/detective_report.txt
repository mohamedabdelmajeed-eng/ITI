       Linux Detective Report

1. Current Shell

Explanation: The shell currently running in this terminal.

2. Shell PID
Command: echo $$
Result: 9360
Explanation: The process ID of the current shell.

3. Parent PID
Command: echo $PPID
Result: 9341
Explanation: The process ID of the parent process.

Explanation: The user currently executing the commands.

Explanation: The main personal directory of the current user.
