# 🚀 Compile & Run

For a standard single-file C++ exercise:

```bash
g++ main.cpp -o app
./app
```

For stricter compiler checking:

```bash
g++ -Wall -Wextra -pedantic main.cpp -o app
./app
```

With a specific language standard:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o app
./app
```

> Adjust the source filename and compiler standard according to the exercise being built.

## 📁 Recommended Exercise Structure

For small exercises:

```text
exercise/
│
├── main.cpp
└── README.md
```

For larger exercises:

```text
project/
│
├── include/
│   └── module.hpp
│
├── src/
│   ├── main.cpp
│   └── module.cpp
│
└── README.md
```

This structure helps separate **interfaces**, **implementation**, and **documentation** as projects grow.

# ✅ Code Quality Checklist

Before considering an exercise complete:

- [ ] Code compiles successfully
- [ ] Compiler warnings are reviewed
- [ ] Variable and function names are meaningful
- [ ] Repeated logic is reduced where practical
- [ ] Functions have clear responsibilities
- [ ] Edge cases are considered
- [ ] Memory ownership is understood
- [ ] Unnecessary global state is avoided
- [ ] Comments explain **why**, not obvious syntax
- [ ] Code formatting remains consistent
